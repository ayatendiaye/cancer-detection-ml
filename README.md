# Cancer Detection with Machine Learning

## Overview
A predictive model to support cancer detection using anonymized hospital data.
This is an educational project and not a medical diagnostic tool.

## Dataset
Anonymized clinical data provided by a hospital. The data is confidential
and is not included in this repository.

## Methodology
1. Data cleaning: missing values, outliers, encoding of categorical variables
2. Exploratory and statistical analysis with IBM SPSS Statistics
3. Train/test split of the data
4. Model training with scikit-learn: Logistic Regression, Decision Tree, Random Forest
5. Model evaluation and comparison

## Evaluation
Models were compared using accuracy, precision, recall, F1-score and the
confusion matrix. Recall was prioritized to reduce missed positive cases.

## Tools
Python, pandas, NumPy, scikit-learn, matplotlib, IBM SPSS Statistics

## Limitations
- Limited dataset size
- No external validation
- Results must not be used for real medical decisions

## Possible improvements
- Cross-validation and hyperparameter tuning
- Larger and more diverse data
- Model explainability (feature importance)
